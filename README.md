# 문자열 덧셈 계산기
## 기능 구현
### 1. 커스텀 구분자가 없는 경우에 각 숫자의 합을 반환
- [x] Console API를 이용해 문자열 입력받기
- [x] 기본 구분자를 통해 숫자 계산하기
- [x] 빈 문자열 입력 시 0 출력하기

### 2. 커스텀 구분자가 있는 경우에 각 숫자의 합을 반환
- [x] 커스텀 구분자를 통해 숫자 계산하기

### 3. 예외 처리하기
- [ ] 입력받은 숫자가 양수가 아닌 경우
- [x] 구분자가 연속으로 두 개 이상 사용된 경우
- [x] 문자열의 끝이 숫자가 아닌 경우 (빈 문자열이 아닐 시)
- [x] 커스텀 구분자 정의를 `\n`으로 끝내지 않은 경우
- [x] 커스텀 구분자를 숫자로 정의한 경우
